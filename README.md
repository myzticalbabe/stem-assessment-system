# stem-assessment-system

Assessment system MVP: JSON question-bank (mcq/numeric), quiz runner, scoring, per-learner progress.

## Usage

```bash
python -m assessment.cli --quiz data/sample_quiz.json --learner Carol --answers answers.json
```

## Tests

```bash
pytest
```
