Question Types

Supported question formats with examples

Single Choice MCQ

Multiple Choice (Single Answer)

Traditional multiple choice with one correct answer. Supports shuffle options and explanation display. 

{ "type": "mcq_single",
  "question": "What is the time complexity of binary search?",
  "options": ["O(n)", "O(log n)", "O(n log n)", "O(n²)"],
  "correct": 1,
  "explanation": "Binary search divides the search space in half each iteration, giving O(log n).",
  "category": "algorithms",
  "difficulty": "easy" }
Shuffle Options Explanations
Multi Choice MCQ

Multiple Choice (Multiple Answers)

Select all that apply. Partial credit scoring supported with configurable penalties. 

{ "type": "mcq_multiple",
  "question": "Which are valid Python data types?",
  "options": ["list", "tuple", "array", "set"],
  "correct": [0, 1, 3],
  "explanation": "list, tuple, and set are built-in. array requires import from array module.",
  "category": "python",
  "difficulty": "medium" }
Partial Credit Configurable Penalties
Numeric Input Calculation

Numeric Questions

Free-form numeric answers with configurable tolerance (absolute or relative). Supports scientific notation. 

{ "type": "numeric",
  "question": "Calculate the derivative of x³ at x=2",
  "answer": 12,
  "tolerance": 0.001,
  "tolerance_type": "absolute",
  "explanation": "d/dx(x³) = 3x². At x=2: 3×4 = 12.",
  "category": "calculus",
  "difficulty": "medium" }
Absolute/Relative Scientific Notation
